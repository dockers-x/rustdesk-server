# v0.2.54

- 内置 Console v0.2.54。录像和自动备份复用「存储配置」中的本地、S3 或 WebDAV 配置项。自动备份移到「系统设置」标签页，支持多个远程目标。
- Console 持久化已使用的 TOTP 时间步，并在升级时加密已有种子。远程备份需配置 age 公钥，上传的是加密归档。
- 延续 v0.2.53 的 Docker 健康检查，由 S6 检查 HBBS 和 HBBR 进程。

镜像为 `czyt/rustdesk-server-s6:v0.2.54` 和 `ghcr.io/dockers-x/rustdesk-server-s6:v0.2.54`。

[Console v0.2.54](https://github.com/dockers-x/rustdesk-console/releases/tag/v0.2.54)
