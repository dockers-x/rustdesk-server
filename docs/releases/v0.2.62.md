# v0.2.62

- S6 内置 Console v0.2.62。从「设备」或「我的设备」打开详情顶部的「网络唤醒」，即可保存网卡 MAC 和发送唤醒包，无需配置网段。
- HBBS 在 WebSocket 断开时清理对应的信令连接，快速重连时保留新连接。
- HBBR 独立转发两个方向的数据，一侧接收缓慢时，反向流量仍可继续发送。

```sh
docker pull czyt/rustdesk-server-s6:v0.2.62
```
