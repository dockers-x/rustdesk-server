# v0.2.49

- S6 内置 Console v0.2.49，新增个人与共享地址簿、回收站、后台角色、操作审计、LDAP 配置和默认策略，支持管理端密码重置和简体中文、英语、俄语事务邮件。
- 配套 hbbs 支持可选的设备准入。Console 与 hbbs 设置同一配对令牌后，管理员可审批或撤销设备。撤销影响后续注册和经 hbbs 协调的新连接。
- 启用 `MUST_LOGIN=Y` 时，hbbs 可对支持该协议的桌面被控端下发键鼠、剪贴板和文件传输限制。
- S6 支持 amd64 与 arm64，镜像为 `czyt/rustdesk-server-s6:v0.2.49` 和 `ghcr.io/dockers-x/rustdesk-server-s6:v0.2.49`。
