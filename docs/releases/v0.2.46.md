# v0.2.46

## S6 内置 Console

- 更新至 Console v0.2.46。一个上线事件可以同时发到 ntfy、Bark、Server 酱或 Webhook。通知规则可选择模板，并可在保存前发送测试。
- 同时包含管理员 TOTP、认证审计和原版客户端地址簿同步修复。 [地址簿 issue #10](https://github.com/dockers-x/rustdesk-console/issues/10)
- S6 固定 Console 多架构镜像摘要 `sha256:15f6fe25c209b3de10ef2f9ad1c694e41969da84b961f7f3c3e0d6b18b20d318`。Classic 部署需要单独升级 [Console v0.2.46](https://github.com/dockers-x/rustdesk-console/releases/tag/v0.2.46)。

## 升级

从较早版本升级时，管理员需要重新登录。尚未绑定 TOTP 的管理员需从 Console 完成绑定。已有设备上报和 Webhook 设置会保留。安全事件从容器 stdout 采集。 [设备通知说明](https://github.com/dockers-x/rustdesk-console/blob/v0.2.46/docs/notification-routing.zh-CN.md) · [安全升级说明](https://github.com/dockers-x/rustdesk-console/blob/v0.2.46/docs/security-upgrade.zh-CN.md)
