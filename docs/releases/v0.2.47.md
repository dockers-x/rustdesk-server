# v0.2.47

## S6 内置 Console

- 内置 Console v0.2.47，修复活跃连接列表残留。没有连接的心跳会清除该设备的连接快照，超过 90 秒未上报的连接会过期。
- 从活跃连接表中点击设备 ID，可在设备列表中定位对应设备。新版通知规则弹窗支持折叠设备范围和多选设备组。 [Console v0.2.47](https://github.com/dockers-x/rustdesk-console/releases/tag/v0.2.47)

## 镜像

- S6 支持 amd64 和 arm64。在 Docker Hub 使用 `czyt/rustdesk-server-s6:v0.2.47`，或在 GHCR 使用 `ghcr.io/dockers-x/rustdesk-server-s6:v0.2.47`。
- S6 固定 Console 镜像摘要 `sha256:357a8dd66e0ee63834063ef7b8c4333ab81735cfb698216a2d3fca22a48fc5d4`。Classic 部署需单独升级 Console。
