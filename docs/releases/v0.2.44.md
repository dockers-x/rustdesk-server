# v0.2.44

## 连接授权

- 强制登录模式下，hbbs 在普通打洞和中继协调前向 Console 实时检查账号会话和目标设备权限，拒绝无关账号、已撤销 token、禁用账号和停用设备。
- 普通用户可连接自己的设备，管理员可连接已登记且启用的设备；地址簿共享不自动授予连接权限。目标绑定的签名 Switch Sides 授权沿用原有路径。
- 授权请求设置超时、并发及响应大小限制，拒绝重定向和无效响应，查询失败时拒绝连接。

## 升级提示

需先升级 Console v0.2.42，并为 hbbs 设置 `MUST_LOGIN=Y`、相同的 `RUSTDESK_API_JWT_KEY` 和 `RUSTDESK_API_RUSTDESK_API_SERVER`。远程 Console 地址须使用 HTTPS；HTTP 仅允许同网络命名空间的显式 loopback IP。

`MUST_LOGIN=N` 继续沿用旧连接方式；IP 直连和已经建立的会话不受这项检查约束。远端密码和人工确认仍由客户端执行，没有修改 RustDesk 客户端。

Console v0.2.42 默认拒绝匿名客户端上报；原版客户端的在线状态、策略同步和远控审计需要在可信入口显式开启兼容选项。详见 Console 安全升级说明。

## 验证与边界

库、二进制及现有集成测试通过；另在无外网的隔离环境运行真实 Console 与 Server 授权调用，验证设备所有者允许、无关账号拒绝及退出后的旧 token 拒绝。没有运行线上探测，没有声称已完成真实浏览器远控会话或 MySQL/PostgreSQL 部署验收。
