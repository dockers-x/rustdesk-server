# v0.2.42

## S6 内置 Console 更新

在 Console v0.2.40 的 Docker 构建成功，并确认 GHCR、DockerHub 的 version/latest 均包含 amd64、arm64 且 digest 一致后发布。S6 基础镜像固定为该版本及 `sha256:19795a390cb7dba574ad11c4471eb3fb249a402bc14ee4ea5f9303fa2af80cd1`，不使用浮动 latest 决定内置 API 版本。

- 新增独立“开发者接入”分类：API 密钥、SDK 与示例、公开 OpenAPI 文档，支持中英文，不依赖自有签名客户端。
- API 密钥按账户、scope 和有效期授权，完整值只在创建时显示，服务端仅保存哈希与展示前缀；支持立即撤销及逐次检查账户状态和管理员权限。
- `/api/v1` 提供 16 项设备、用户、设备组、策略、个人通讯录与账户资料管理操作；`/api/v1/openapi.json` 对外公开，内置页面可查看与下载。
- Rust、Go、Node.js SDK v0.1.0 分别发布于 `lib-x/rustdesk-console-sdk-rs`、`lib-x/rustdesk-console-sdk-go`、`lib-x/rustdesk-console-sdk-ts`。Rust crate 为 `rustdesk-console-sdk`；TypeScript 从 GitHub 安装，未发布 npm registry。

## 升级与验证

Console 自动创建 `developer_keys` 表，并执行迁移 274，为设备组增加默认空的 `note` 字段。升级前备份数据库与配置；原有自有签名密钥、功能开关和持久化目录无需重置，继续保留 `/app/conf/features`。

Server 45 项库测试、Console 241 项 Rust 测试、7 项 Web 测试及生产构建通过。三种 SDK 各自完成 16 项真实接口及 401/403/404 错误验证，远程安装与各自 CI 均通过；Console 两个 musl 包已核验 SHA256，x86 发布包通过真实启动、鉴权、权限和撤销烟测。

## 回归面

本次 Server 仅更新 `docker/Dockerfile` 的 S6 Console 基础镜像与发布说明。hbbs/hbbr Rust 源码、客户端、shared 子模块、会话协议均不变；Classic 镜像不内置 Console。本 fork 发布标签为 v0.2.42，上游组件 Cargo 版本仍为 1.1.17。独立部署 Console 的用户需另行升级到 v0.2.40。

Console 的既有改动仅涉及新路由/模块接入、数据库初始化与设备组 note 的兼容迁移，以及导航、路由权限和中英文文案入口；原有客户端登录、后台会话与部署接口不改用 API 密钥。
