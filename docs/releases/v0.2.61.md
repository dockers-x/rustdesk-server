# v0.2.61

- S6 内置 Console v0.2.61，提供设备活动、一次性入网码、客户端分发和 Wake-on-LAN。
- HBBS 同步 Console 封禁列表，按设备 ID 拦截注册及新连接。HBBS 和 HBBR 都执行精确 IP 与 CIDR 规则，HBBR 也会关闭命中网络规则的活动中继。
- 配对的 HBBS 为限时访客链接分配专用中继，过期或撤销时由 Console 关闭会话。
- Console 数据库升级至 schema 292。

```sh
docker pull czyt/rustdesk-server-s6:v0.2.61
```
