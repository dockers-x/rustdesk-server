# v0.2.59

- S6 内置 Console v0.2.59。登录后可在个人中心绑定和解绑 OIDC 账号，后续可通过已绑定的身份登录。
- 默认要求先绑定。站点和提供商均允许自动注册时，已初始化的站点可创建普通用户。
- Console 支持通过通用 `RUSTDESK_API_OIDC_*` 环境变量配置提供商。数据库升级至 schema 285。

```sh
docker pull czyt/rustdesk-server-s6:v0.2.59
```
