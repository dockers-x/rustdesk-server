# v0.2.51

- S6 内置 Console v0.2.51，新增本地运维 CLI、分类型日志保留和按范围委派管理。
- HBBS 提供只读 Geo 路由试算，可查看运行中的规则版本、匹配结果、候选中继和回退原因。试算不会推进中继轮询。
- Console 更新了设备在线指示、登录平台摘要和文件审计详情。审计及录屏记录的设备 ID 支持复制，有权限时可跳转到地址簿或设备列表。
- S6 镜像支持 amd64 和 arm64。可使用 `czyt/rustdesk-server-s6:v0.2.51` 或 `ghcr.io/dockers-x/rustdesk-server-s6:v0.2.51`。

[Console v0.2.51](https://github.com/dockers-x/rustdesk-console/releases/tag/v0.2.51)
