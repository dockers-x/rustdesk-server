# v0.2.60

- S6 内置 Console v0.2.60。Geo Relay 可选择 MaxMind 官方或自定义 MMDB 下载源，并支持一键填入 P3TERX。手动下载和自动更新共用所选来源。
- SMTP 配置和测试邮件移至「系统设置 → 邮箱设置」。
- Console 数据库升级至 schema 286，兼容已有 GeoIP 下载地址。

```sh
docker pull czyt/rustdesk-server-s6:v0.2.60
```
