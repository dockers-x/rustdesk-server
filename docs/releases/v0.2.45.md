# v0.2.45

## 在线状态

- S6 镜像内置 Console 更新至 v0.2.44，撤回对原版客户端上报的默认拦截，恢复设备在线状态、集中策略同步和远控审计。
- 保留 v0.2.44 的实时连接授权，以及 Console 的设备归属和管理写入保护，不要求修改 RustDesk 客户端。

## 升级提示

S6 用户升级镜像并重启服务即可使用新的默认配置；Classic 镜像不内置 Console，需单独升级 Console 至 v0.2.44。

如果已有配置文件或环境变量显式关闭兼容上报，请删除该覆盖或设置 `security.allow-legacy-device-reports: true`，再重启 Console；对应环境变量为 `RUSTDESK_API_SECURITY_ALLOW_LEGACY_DEVICE_REPORTS=true`。

本次 hbbs/hbbr 源码与 v0.2.44 相同，`MUST_LOGIN` 的连接权限检查保持不变；原版匿名上报不能作为可信设备认证或不可抵赖审计。
