# v0.2.55

- S6 内置 Console v0.2.55。设备、连接和审计列表现在可以重试查询、清空筛选，窄屏导航和键盘操作也更方便。
- 大型设备列表的总览统计改由数据库汇总。活跃连接的心跳分批写入，并在同一事务内提交。
- 首次启动会将 Console 数据库从 schema 282 升到 283 并创建索引。升级前请备份数据库，大型实例请为建索引预留时间。回退至 v0.2.54 时请恢复升级前的备份。

Docker Hub 和 GHCR 均提供 `linux/amd64`、`linux/arm64` 镜像。

```sh
docker pull czyt/rustdesk-server-s6:v0.2.55
```
