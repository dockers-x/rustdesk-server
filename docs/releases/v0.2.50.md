# v0.2.50

- S6 内置 Console v0.2.50，设备准入页新增配置说明和部署令牌入口，站点设置支持自定义 Logo 和浏览器标签页图标。
- 地址簿可选择已有标签、在弹窗内勾选设备导入，并在窄屏使用回收站。部署令牌权限改用标签选择。
- S6 支持 amd64 和 arm64，镜像为 `czyt/rustdesk-server-s6:v0.2.50` 和 `ghcr.io/dockers-x/rustdesk-server-s6:v0.2.50`。
