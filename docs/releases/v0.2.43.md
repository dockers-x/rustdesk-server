# v0.2.43

## 合并官方上游

`forapi` 合并 RustDesk 官方 `master` 至 `680b60395ecf99a76f74a1d934e453bb6e5e0aa2`（2026-11-08），包含上次共同基线后的 11 个提交。

- hbbs 校验 relay UUID，限制 TCP/WebSocket 消息大小，限制 WebSocket 握手时间。
- hbbr 限制初始配对请求大小及双向写入等待时间，修复旧等待连接清理时误删复用 UUID 的问题。
- 保留 WebSocket 转发 IP 对应的连接端口，修复 IPv4 和 IPv4-mapped IPv6 客户端的 relay 名单匹配。
- 管理 console 响应完整写入，并设置写入期限；同步上游固定版本的 WebSocket 依赖。
- 冲突解决保留本 fork 的登录鉴权、加密 key exchange、switch-grant、动态配置、IPv6/WebRTC transport hints 和区域 relay 策略。

## S6 内置 Console

S6 更新至已完成 Docker 构建和产物验证的 Console v0.2.41，固定基础镜像 digest：`sha256:81f745205a3040829d25fa8edb402852a0bb40b8144b72ec43565c2210059b71`。

- 保留 Console v0.2.40 的开发者 API、API keys、SDK 示例及公开 OpenAPI。

## 升级提示

升级前备份数据库、配置和密钥，继续持久化 `/app/conf/features`；无需重新生成密钥或重置功能开关。Classic 镜像不内置 Console，独立 Console 部署需要另行升级。

hbbs 新增 `MAX_MESSAGE_KB`：默认 64 KiB，非法值或 0 使用默认值，上限 64 MiB。默认可容纳约 5000 个常规 ID 的在线查询；特别长的自定义 ID 或更大的批量查询可按需调整。hbbr 初始配对请求限制为 128 KiB，配对后的会话使用相应 transport 限制。

## 回归面与验证

运行时变化限于 `src/rendezvous_server.rs` 的 relay 校验、消息边界、WebSocket 握手/转发地址及管理响应，以及 `src/relay_server.rs` 的配对、写入期限、管理响应和名单匹配。`Cargo.toml`/`Cargo.lock` 同步上游 WebSocket 依赖；`docs/environment-variables.md` 同步新配置说明，`CLAUDE.md` 删除沿用上游。S6 Docker 基底更新不可避免地升级内置 Console；客户端、shared 子模块及本 fork 其他功能模块未修改。

库测试和二进制测试覆盖原有 fork 行为与上游新增测试；所有二进制以 `--all-features --locked` 构建验证。发布标签使用本 fork 的 v0.2.43；上游 Cargo 组件版本仍为 1.1.17。
