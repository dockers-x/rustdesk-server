# v0.2.52

- S6 内置 Console v0.2.52，带来连接和文件审计 CSV 导出、跨组连接授权及 SQLite 多目标备份。
- HBBS 和 HBBR 支持仅在本机访问的存活及就绪接口。S6 健康检查还覆盖启用时的 Console，并指出失败组件。
- 设置 `LOG_FORMAT=json` 可输出结构化日志，设置 `DISABLE_UPDATE_CHECK=Y` 可关闭 HBBS 上游版本检查。
- 新增 S6 离线备份与验证恢复命令，可保存两套 SQLite 数据库、配置和密钥。归档可由 Console 命令分别上传至 S3 和 WebDAV。
- Linux 二进制归档附带 SHA-256 清单。上游同步指定官方发布标签，在隔离工作区通过真实进程回归后才更新分支。

S6 镜像支持 amd64 和 arm64。可使用 `czyt/rustdesk-server-s6:v0.2.52` 或 `ghcr.io/dockers-x/rustdesk-server-s6:v0.2.52`。
